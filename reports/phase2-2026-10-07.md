## Findings worth knowing

- **Groq free tier is tight:** ~8K input and 1K output tokens per minute,
  200K per day for `qwen/qwen3.8-27b`. The app now waits out short pauses;
  tools chunk their requests. One full evaluation uses most of a day.
- **Disk:** the VM hit 100 % during a Docker rebuild. Code is bind-mounted
  into the running container, so rebuilds are rarely needed; the smoke
  test reuses the built image (`SMOKE_BUILD=1` to force a rebuild).
- **GitHub push:** for about an hour every push (even a zero-data branch
  creation) was rejected with `remote: Internal Server Error` (request ID
  `C88B:1D5C60:5B3E65:61CD40:6AC66170`) while githubstatus.com showed all
  systems operational; it was transient and the push later succeeded.
  The first CI run then failed because two new unit tests imported
  LangChain, which the fast job intentionally does not install; fixed by
  removing the import, and the next run was green.
- **Branching:** everything is on branch `anmol/phase-2` (16 commits ahead
  of `main`). `origin/main` was left untouched for the team to merge.
